# Репитеры — откуда взяты данные

Дата сбора: **29.09.2026**. В список приложения попали только репитеры, у которых есть **аналоговый FM или C4FM (Fusion)**, потому что только эти режимы умеет FT-70D.
DMR, D-STAR, TETRA, NXDN, P25 и M17 — не для этой рации, их нет в списке.

**Важно:** в RepeaterBook указаны частота выхода и знак сдвига, но не его величина.
Для таких записей в приложении стоит стандартный сдвиг IARU Region 1 (2 м — 0,6 МГц, 70 см — 7,6 МГц) с пометкой «⚠️ сдвиг стандартный — уточнить».
Репитеры с частотой выхода вне 144–146 / 430–440 МГц (например, 446.xxx) добавлены с предупреждением.
