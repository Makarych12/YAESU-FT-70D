# Подтверждённые факты о Yaesu FT-70DR / FT-70DE

Источники (официальные документы Yaesu, скачаны 29.09.2026 со страницы модели на yaesu.com):

- **OM** — FT-70DR/DE Operating Manual, файл `FT-70DR_DE_OM_ENG_EH051M202_1809R-CY-1.pdf` (44 стр.). Номера страниц ниже — **печатные** (внизу страницы мануала).
- **AM** — FT-70DR/DE Advance Manual, файл `FT-70DR_DE_AM_ENG_1907-F.pdf` (47 стр.).
- **FWI** — FT-70DR/FT-70DE Firmware Update Information (Rev 1) 11-08-17.
- **FWM** — FT-70DR/DE Main Firmware Update Instruction Manual `…_ENG_2206-C.pdf` (из архива `FT-70D_ver111(EXP).zip`).
- **ADMS** — ADMS-10 Instruction Manual `ADMS-10_FT-70D_IM_ENG_2211-C.pdf`.

## ⚠️ Поправка к ТЗ: нумерация меню SET у европейской версии

В ТЗ сказано «пункт меню **63: W-DGID**». Это номер **американской** версии (FT-70DR, USA).
У **FT-70DE** (EXP / Европа) нет пункта 61 WX ALT (погодное оповещение, только для США), поэтому последние пункты сдвинуты на один:

| USA (FT-70DR) | EXP/EU (FT-70DE) | Пункт |
|---|---|---|
| 61 | — (нет) | WX ALT |
| 62 | **61** | W/N.DEV |
| 63 | **62** | W-DGID |
| 64 | **63** | MYCALL |

Источник: OM стр. 37 (сноска «*: USA Version»), AM стр. 27 и 42. В приложении везде используется нумерация FT-70DE и в скобках — американская.

## Кнопки (OM стр. 5)

| Кнопка | Нажатие | [F] + кнопка | Удержание > 1 с |
|---|---|---|---|
| GM | вкл/выкл Group Monitor | — | вкл/выкл GM |
| F | «вторая функция» (значок F) | снимает F | вход в меню SET |
| MODE | FM(AM) → DN → VW* | имя канала ↔ частота | установка DG-ID |
| HM/RV | Home-канал | реверс на репитере | записать Home-канал |
| AMS | выбор режима передачи при AMS (TX AUT / TX FM / TX DIG) | **WIRES-X** | вкл/выкл AMS |
| BAND | следующий диапазон вверх | диапазон вниз | — |
| V/M | VFO ↔ память | Dual Receive (DW) | запись в память |
| 1 (TX PO) | цифра | мощность | «1» + нули |
| 2 (SCAN) | цифра / ABC | сканирование | «2» + нули |
| 3 (DTMF) | цифра / DEF | режим DTMF | «3» + нули |
| 4 (STEP) | цифра / GHI | шаг частоты | «4» + нули |
| 5 (SQ TYP) | цифра / JKL | тип шумодава/тона | «5» + нули |
| 6 (CODE) | цифра / MNO | частота CTCSS / код DCS | «6» + нули |
| 7 (P1) | цифра / PQRS | программируемая кнопка P1 (по умолч. 12 DC VLT) | «7» + нули |
| 8 (P2) | цифра / TUV | программируемая кнопка P2 (по умолч. 47 RX MOD) | «8» + нули |
| 9 (SKIP) | цифра / WXYZ | пропуск / выбранный канал | «9» + нули |
| 0 (RPT) | цифра / пробел - / ? ! | направление сдвига (−, +, симплекс) | «0» + нули |

Боковые: PTT (передача; в меню — сохранить и выйти), MONI/T.CALL (EU: 1750 Гц; [F]→MONI = уровень SQL), VOL (держать + крутить DIAL = громкость), POWER/LOCK (удержание — вкл/выкл, короткое — блокировка).

## Индикатор MODE/STATUS (OM стр. 4, 17, 13)

- Приём FM — зелёный; приём C4FM — синий; приём цифровых данных — зелёный + белый.
- Сигнал с чужим DG-ID/DP-ID/тоном/DCS — мигает синим.
- Передача FM — красный; передача C4FM — красный + синий.
- GM: станция в зоне — голубой.
- Зарядка (EU): левая часть красная, на экране «CHGING»; зарядка окончена — зелёный, «CHGFUL». «CHGERR» — ошибка.

## Прошивка (FWI, FWM)

- Последняя MAIN — **1.11** (08.11.2017). Для европейской версии — архив **`FT-70D_ver111(EXP).zip`** («EXP» = EU/EXP/AUS/CHN). Регион указан на наклейке с серийным номером на коробке (DST).
- Что добавила 1.11: WIRES-X, пункт меню W-DGID (в USA — 63, в EU — 62), исправление редкой ошибки зарядки полностью разряженного аккумулятора.
- Обновление: только Windows 8.1/10/11, нужен .NET 3.5 SP1, драйвер из программы обновления («USB Driver Install»).
- **Переключатель PROGRAM** (трёхпозиционный, под крышкой DATA/EXT DC IN, справа): вверх — прошивка MAIN, по центру — обычная работа, вниз — прошивка DSP. Переключать булавкой.
- Аккумулятор снять, питание — от адаптера через EXT DC IN.
- **После прошивки нужен полный сброс, вся память стирается** (FWM стр. 15, 20).
- В диспетчере устройств должно быть «Generic Boot USB Direct» (раздел Renesas USB Development Tools). Если видно «Renesas USB1653 USB Boot Mode Device», драйвер нужно заменить вручную (FWM стр. 11–14).

## ADMS-10 (ADMS)

- Бесплатная программа Yaesu, для Windows 8.1/10/11. Кабель — **штатный USB-кабель** из комплекта.
- Подключение: снять аккумулятор → вставить адаптер в EXT DC IN (на экране «EXT DC» или «CHG ERR») → включить рацию → вынуть адаптер (рация остаётся включённой) → USB-кабель в DATA до щелчка → **удерживать [AMS] и снова вставить адаптер** → на экране «ADMS».
- Драйвер: в диспетчере устройств «Unknown device» → Обновить драйвер → указать папку ADMS-10 → «FT-70D communication device (COMxx)».
- Чтение из рации: «Get Data from FT-70D» → OK → **[BAND] на рации** → «--TX--».
- Сначала обязательно прочитать данные из рации, потом редактировать.
