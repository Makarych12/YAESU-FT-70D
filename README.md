# FT-70D — просто и понятно

Офлайн-справочник по радиостанции Yaesu FT-70DE: 108 пошаговых инструкций, меню SET, поиск, репитеры и мастер настройки. Устанавливается на телефон как веб-приложение.

## Запуск

```bash
npm ci
npm run dev
```

Проверки и производственная сборка:

```bash
npm run check
npm run test
npm run build
```

Готовые файлы появятся в `dist/`. Для проверки офлайн-режима откройте сборку через `npm run preview` по HTTPS или на `localhost` и дождитесь установки сервис-воркера.

Факты и ссылки на источники находятся в папке `research/`. Часть процедур помечена в приложении как требующая проверки на самой рации.
